# Гігієна репозиторію

**Навіщо.** Курс вимагає чистий репозиторій. У git лежить лише те, що
написано руками або є свідомим артефактом здачі. Згенероване, локальне й
секретне туди не потрапляє.

## Що не потрапляє в репозиторій

| Шаблон | Чому |
|---|---|
| `node_modules/` | відтворюється через `npm ci` з lockfile |
| `dist/`, `coverage/`, `*.tsbuildinfo` | артефакти збірки й тестів, відтворюються командою |
| `*.log` | локальний вивід. Звіти для здачі — лише в `reports/labN/` |
| `.env`, `.env.*` (крім `.env.example`) | секрети й локальні налаштування |
| `.DS_Store`, `.idea/`, `.vscode/`, `.claude/settings.local.json` | налаштування ОС, IDE та інструментів конкретної машини |

Ці шаблони дублюються в `.gitignore`. `.gitignore` захищає від випадкового
`git add`, а CHK-09 — від того, що вже потрапило в індекс.

## Файли без розширення

Файл без розширення в імені — найчастіше випадковість: вивід команди, бекап,
файл, створений опискою. Тому такі файли дозволені лише за списком:

- `Makefile`
- `LICENSE`
- `.gitignore`
- `.nvmrc`
- `.editorconfig`
- `.husky/pre-commit`
- `.husky/commit-msg`
- `.husky/pre-push`

Новий файл без розширення додається в цей список тим самим комітом, що й
файл.

## Звіти

- **Розміщення.** Згенеровані звіти для здачі лежать лише в `reports/labN/` і
  створюються `make verify`.
- **Ручні правки.** Їх не правлять руками. Навіщо: звіт є доказом, лише якщо
  він відтворюваний.

## Як перевіряється

- **Заборонені шаблони й файли без розширення:** CHK-09 у
  [checks.md](checks.md) — скрипт над `git ls-files` у `make check`.
- **Секрети у вмісті файлів:** CHK-09 їх не шукає. Перевіряється вручну на
  рев'ю (MAN-06), автоматичного сканування немає.
- **Звіти не правлені вручну:** `make verify` перегенеровує їх. Непорожній
  `git diff reports/` після цього означає розбіжність.
