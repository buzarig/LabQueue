# ADR-0015: CI на GitHub Actions

- Статус: запропоновано
- Дата: 2026-09-30
- Промпт: ai/lab1/010-adr-stack.md

## Контекст і проблема

sf-3 додав CI в обсяг: `make check` на push і PR. Hook-и обходяться через
`--no-verify`, тож CI — єдиний бар'єр, який не залежить від дисципліни
розробника. Курс також вимагає узгодженого ланцюга код ↔ тести ↔ конвеєр.
Треба обрати CI-платформу.

## Чинники рішення

- **Інтеграція з PR**: статус перевірки видно прямо в PR, яким здається лаба.
- **Та сама команда**, що й локально (`make check`, [ADR-0014](0014-make-yak-interfeis-komand.md)).
- **Безкоштовно** для навчального репозиторію.
- **Повна історія для перевірки комітів**: CHK-07 і CHK-08 перевіряють
  `main..HEAD`.

## Розглянуті варіанти

1. **GitHub Actions** — workflow `.github/workflows/check.yml`.
2. **GitLab CI** — з перенесенням репозиторію або дзеркалом.
3. **Без CI** — лише hook-и, як в оригінальній spec до sf-3.

## Рішення

Обрано **GitHub Actions**. Workflow `check.yml`:
- **Коли:** на `push` і `pull_request`.
- **Кроки:**
  - checkout з повною історією (`fetch-depth: 0`) і гілкою `main`;
  - Node 24 з `.nvmrc`;
  - `make check`.

Більше в workflow нічого немає. Уся логіка живе в `Makefile`.

### Наслідки

- **Добре:**
  - статус CI видно в PR здачі;
  - CI і розробник запускають одну команду, тож «у мене працює» не
    розходиться з конвеєром;
  - обійти перевірку через `--no-verify` вже не вийде непомітно.
- **Погано / ціна:**
  - прив'язка до GitHub;
  - повний `fetch-depth` трохи сповільнює checkout;
  - червоний CI сам по собі merge не блокує. Для цього потрібен branch
    protection, а це налаштування репозиторію, яке автор вмикає окремо.

## Плюси й мінуси варіантів

### GitLab CI

- Плюс: зрілий CI, зручні pipeline-и.
- Мінус: здача йде PR на GitHub, тож статус перевірки з GitLab до PR не
  потрапляє без додаткових інтеграцій → відкинуто.

### Без CI

- Плюс: нічого не налаштовувати.
- Мінус: єдиний бар'єр — локальні hook-и, які обходяться через `--no-verify`.
  Наскрізна вимога курсу (ланцюг з конвеєром) і sf-3 → відкинуто.
