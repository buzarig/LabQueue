# ADR-0014: Make як єдиний інтерфейс команд

- Статус: запропоновано
- Дата: 2026-09-30
- Промпт: ai/lab1/010-adr-stack.md

## Контекст і проблема

Курс вимагає, щоб артефакти відтворювались через `make <ціль>`, а DEFENSE
містить рядок «перевірка: `make <ціль>` → результат». `make check` і
`make verify` уже фігурують у spec і стандартах. Рішення про Make фактично
прийшло з вимог курсу, але альтернативи в нього реальні, тож фіксуємо його
явно (К3).

## Чинники рішення

- **Одна точка входу** для людини, hook-ів і CI: однакові команди скрізь.
- **Вимога курсу** — `make`.
- **Залежності між кроками**, наприклад:
  - `npm ci`, якщо змінився lockfile (sf-4);
  - `verify` залежить від `check`.
- **Доступність** на машині рев'юера без встановлення.

## Розглянуті варіанти

1. **Make** (`Makefile`), який викликає npm-скрипти й інструменти.
2. **Лише npm scripts** у `package.json`.
3. **just** або **Taskfile** (go-task) — сучасні запускачі задач.

## Рішення

Обрано **Make**.
- **Цілі:** `check` і `verify` — публічні, решта — допоміжні.
- **Встановлення пакетів.** Ціль `node_modules` залежить від
  `package-lock.json`. Так реалізується правило «`npm ci`, якщо
  `node_modules` відсутній або lockfile новіший» (sf-4).
- **Hook-и й CI** викликають лише цілі Make, а не інструменти напряму.

### Наслідки

- **Добре:**
  - одна команда однаково працює локально, у pre-push і в CI;
  - правило «lockfile новіший» природно виражається залежністю цілей Make;
  - Make є на macOS і Linux без встановлення;
  - формат DEFENSE (`make <ціль>`) виконується буквально.
- **Погано / ціна:**
  - синтаксис Makefile крихкий: табуляції, `.PHONY`, екранування `$`;
  - на Windows без WSL Make немає. Для курсу це прийнятно;
  - частина логіки дублюється між `Makefile` і `package.json`.

## Плюси й мінуси варіантів

### Лише npm scripts

- Плюс: нуль додаткових інструментів, знайомо кожному Node-розробнику.
- Мінус: залежності між кроками й умову «lockfile новіший» довелося б писати
  скриптами. Курс прямо вимагає `make <ціль>` → відкинуто. npm scripts
  лишаються нижнім рівнем, який викликає Make.

### just / Taskfile

- Плюс: чистіший синтаксис, кросплатформеність.
- Мінус: окремий бінарник, який треба встановити на машині рев'юера й у CI.
  Це ламає «одну команду на свіжому клоні» (К5), а курс називає саме
  `make` → відкинуто.
