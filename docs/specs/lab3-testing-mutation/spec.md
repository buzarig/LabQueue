# spec: Лаба 3 — тестування електронної черги

## Що і навіщо

У лабі 2 реалізовано електронну чергу з адаптерами memory та PostgreSQL. Мета лаби 3 — перевірити систему на рівнях unit, integration та E2E, виміряти покриття, провести мутаційне тестування й посилити слабкі тести.

Деталі сценаріїв — у `data.md` лаби 2, зміни — у `spec-fix.md`, правила домену — в `architecture.md` лаби 1, робота з ШІ — у `standards/ai-workflow.md`.

## Обсяг

Тестуємо наявну поведінку без додавання нових функцій. Не робимо UI, авторизацію, деплой або зміну бізнес-правил.
