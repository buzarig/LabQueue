## sf-1. Поріг покриття `transitions.js` — гілки й функції

- **Було:** критерій 12: «Ціль — 100% branch coverage `transitions.js`,
  мінімум 80%; нижче порогу `make test` падає».
- **Стало:** ціль — 100 % гілок і функцій `transitions.js`, мінімум 80 % для
  кожного з двох показників; нижче будь-якого порогу `make test` падає.
- **Чому:** V8 рахує гілки лише у викликаних функціях. Функція, яку не
  викликав жоден тест, не додає непокритих гілок, тому поріг лише гілок
  можна пройти, пропустивши цілу функцію. На пробі з двома викликами
  вийшло 75 % гілок і 29 % функцій ([ADR-0039](../../adr/0039-c8-pokryttia.md)).
  Новий критерій не з'являється — уточнено чинний.
- **Промпт:** [013](../../../ai/lab3/013-pohodzhuiu-variant-a.md) — вибір
  варіанта «а»; [014](../../../ai/lab3/014-pochynai-zakryi-sf.md) — правку
  вносить ШІ.
