# spec-fix: журнал змін spec лаби 4

`spec.md` містить актуальну версію. Тут записані зміни прийнятого тексту.
Змінене місце позначене `(sf-N)`. Формат описано в
[standards/spec-format.md](../../../standards/spec-format.md).

## sf-1. Два PR до ревʼю для доказу деплою

- **Було:** «Малий PR із CD можна злити до ревʼю викладача для доказу автодеплою. Правила мерджу діють і для нього.»
- **Стало:** «Два PR (CD, міграції даних) можна злити до ревʼю для доказу деплою. Правила мерджу діють і для них (sf-1).»
- **Чому:** за критерієм 9 спочатку потрібен деплой із `main`, щоб через API створити заняття з `room = "  101  "`. Потім потрібен другий деплой із міграцією даних. Попередній виняток покривав тільки один PR.
- **Промпт:** [008](../../../ai/lab4/008-variant-a-komitymo-prompty.md) (вибір варіанта (а)), [009](../../../ai/lab4/009-vidpovidi-konfih-railway-sf1.md) (sf-1 пише автор).

## sf-2. PR для доказу деплою без ліміту кількості

- **Було:** «Два PR (CD, міграції даних) можна злити до ревʼю для доказу деплою. Правила мерджу діють і для них (sf-1).»
- **Стало:** «PR для CD чи міграцій можна зливати до ревʼю для доказу деплою. Правила мерджу діють і для них (sf-2).»
- **Чому:** Railway Wait for CI не запустив деплой коміту `a36005b`, бо перевірки Render і Cursor залишилися незавершеними. Для повторної перевірки деплою потрібен третій малий PR.
- **Промпт:** повідомлення в чаті від 25.11.2026 з вибором варіанта (а) і запитом додати sf-2.
