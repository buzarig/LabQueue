# Аудит лаби 1

Аудит буде написано пізніше. Поки що тут лише список кандидатів.

## Кандидати в «зрізані кути» ШІ

1. **Самостійні рішення замість питання.** У коміті `6928e3f` ШІ сам вирішив
   три неоднозначності, хоча домовленість була «зупиняйся й питай»
   ([002](../../ai/lab1/002-answers-and-conventions.md), «Домовленості»):
   - прибрав статус «пропуск»;
   - визначив, що вважається «кодом» у К4;
   - не додав перехід «викликаний → вийшов».

   ШІ позначив ці рішення після коміту, а не до нього. Фідбек автора:
   [004](../../ai/lab1/004-review-sf.md). Виправлення: sf-12, sf-13.

2. **Загублене питання: процесна розбіжність.**
   - **Що сталося.** У першій відповіді ШІ спитав, чи «топ-3 розбіжності
     проти spec» з шаблону DEFENSE — те саме, що «зрізані кути» ШІ з К13.
     У відповідях 002–003 цей пункт загубився.
   - **Що зробив ШІ.** Питання повторно не поставив. У коміті `85f6bb4`
     (`definition-of-done.md`) сам розвів їх на два списки й позначив це
     лише після коміту. Це та сама схема, що в кандидаті 1, хоча правило
     «питання до коміту» вже стояло в `standards/ai-workflow.md`.
   - **Фідбек автора:** [007](../../ai/lab1/007-review-standards.md), п.6.
     Рішення: в аудиті три розділи — розбіжності реалізації зі spec, зайві чи
     неправильні залежності, «зрізані кути» ШІ. П.2 DEFENSE — розбіжності
     реалізації зі spec.
   - **Урок для процесу.** Питання без відповіді ШІ має повторити до коміту,
     а не закривати власним рішенням.

3. **Обмеження, яке тримається домовленістю, а не перевіркою.**
   - **Що сталося.** За [ADR-0005](../adr/0005-koordynatsiia-zavershennia-zaniattia.md)
     перевести заняття в «завершене» через API `sessions` може лише `queue`.
     Інакше обходиться перевірка I10 (немає «здає», активні записи → «не
     встиг»).
   - **Чому це не ловиться.** dependency-cruiser (CHK-04) перевіряє напрями між
     модулями, а не виклики окремих функцій. Тож виклик цього переходу з
     іншого місця `make check` не зупинить.
   - **Звідки взялося.** Ціна обраного варіанта ADR-0005, записана ШІ в
     розділі «Наслідки». Автор позначив це кандидатом у
     [010](../../ai/lab1/010-adr-stack.md).
   - **Можливе виправлення** (вирішити в аудиті):
     - правило dependency-cruiser на рівні файлу — винести перехід в окремий
       файл `sessions`, доступний лише з `queue`. Але це суперечить К9 (одна
       точка входу модуля) і потребує sf;
     - або тест, який доводить, що завершення поза `queue` неможливе.
